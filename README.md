# TRPG World Builder

Simple browser-based TRPG world building tool for GMs.

## First MVP

- Create tagged entries for places, people, events, factions, and objects
- Connect entries with relationship labels
- Keep a timeline of story beats
- Save data locally in the browser
- Export and import JSON snapshots

## Run locally

From this folder:

```bash
python3 -m http.server 8001
```

Then open:

```text
http://127.0.0.1:8001
```
